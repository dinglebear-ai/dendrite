# Vibin

Knowledge, development, and homelab operator skills for domain-aware session
closeout, code and maintenance logging, decisions, runbooks, reports, standards
alignment, homelab context refresh, service deployment, repository publishing,
merge readiness, GitHub PR work, CI debugging, Windows helpers, the Lab MCP
gateway, Paperless, Jetpack Compose, and SWAG reverse-proxy configuration.

`create-swag-config` uses Vibin-managed `SWAG_*` settings plus direct SSH/file
writes. Configure `SWAG_EDGE_HOST`, `SWAG_PUBLIC_BASE_DOMAIN`, and
`SWAG_PROXY_CONFS_PATH` through plugin settings or environment variables before
using it.
